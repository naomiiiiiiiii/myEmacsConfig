This is my silly and cute emacs config. It includes 
- The emacs logo replaced with a picture of a baby harp seal
- [Kaomoji](https://en.wikipedia.org/wiki/Kaomoji) inserted at random places
- pastel colors on a high contrast background (inspired by https://github.com/vic/rebecca-theme)
-  a loopy cursive comments font (taken from https://github.com/melissaboiko/girly-notebook-theme)
-  The option to turn the text rainbow colored (using https://github.com/xuchunyang/lolcat.el)
-  Automatically rainbow-colored welcome page, with the option to disable for readability (repurposing code from https://github.com/xuchunyang/lolcat.el)

This repo is mostly a backup so that when I break my config beyond repair (again), I don't have to start from scratch. 
I don't expect anyone else to use this ridiculous thing. I have committed all files which differ from the standard spacemacs install. 

If someone else is looking at this repo, please know that much of this code is not original. I have copied code from other public repositories (linked above) and when stuck, used an AI coding agent to help me. Making this has helped me learn about elisp and spacemacs development. The result is a functional and pretty editor :). Perhaps it will give you ideas for how you beautify your own editor.
